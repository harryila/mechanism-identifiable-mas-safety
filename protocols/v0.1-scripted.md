# v0.1-scripted archive

**Status:** archived deterministic reference, retained for reproducibility.

`v0.1-scripted` is the two-workflow implementation that shipped with the initial
public release. It is an executable specification and test oracle for the
scenario contract, intervention diffs, policies, simulated tools, defense
visibility, trace schema, and analysis code. It is **not** live-agent evidence.

The archived design emits 192 deterministic traces:

- 160 paired core traces from two workflows, four mechanisms, mechanism on/off,
  matched safe/unsafe variants, and five primary defense conditions;
- 16 single-agent/full-context reference traces; and
- 16 omniscient-monitor reference traces.

The fixed `ScriptedBackend` returns the scenario-declared typed action. Therefore
its LGH and defense patterns establish only that the formal construction is
executable and internally consistent. They do not estimate model behavior,
failure prevalence, refusal behavior, defense effectiveness on live agents, or
generalization to other workflows.

The archived materials are all tag-bound:

- [two-workflow specification](https://github.com/harryila/mechanism-identifiable-mas-safety/blob/v0.1.0-scripted/docs/pilot_workflows_spec.md);
- [deterministic traces and analyses](https://github.com/harryila/mechanism-identifiable-mas-safety/tree/v0.1.0-scripted/outputs/pilot);
- [executed analysis companion](https://github.com/harryila/mechanism-identifiable-mas-safety/blob/v0.1.0-scripted/notebooks/pilot_analysis.ipynb); and
- the repository's [`v0.1.0-scripted` tag](https://github.com/harryila/mechanism-identifiable-mas-safety/tree/v0.1.0-scripted),
  the authoritative source for the original hashes and validation report.

The current branch's `outputs/pilot/` is a v0.2 scripted preflight, not the v0.1
archive. Use the archived tag when reproducing v0.1. The active research plan is
[`v0.2-live`](v0.2-live.md); v0.1 outputs must never be pooled with or substituted
for live-agent outcomes.
